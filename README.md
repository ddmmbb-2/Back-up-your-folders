# Folder Versions

使用 **Rust** 製作的 Windows 離線資料夾版本管理工具。

不需要 Git、網路或安裝程序，只要將單一 EXE 放進專案資料夾，就能建立完整 ZIP 快照，並在需要時恢復舊版本。

## 功能

- **快照備份**：輸入版本名稱、修改內容，按下「存檔」即可備份整個資料夾。
- **版本復原**：從歷史清單選擇版本，按下「恢復」即可還原。
- **自動保護**：還原前先建立目前資料夾的安全快照。
- **完全離線**：不需要帳號、伺服器或資料庫。
- **免安裝**：編譯後只需一個 EXE。

## 使用方式

1. 將 `folder-versions.exe` 放進要管理的資料夾。
2. 雙擊執行，預設開啟「快照備份」。
3. 輸入「名稱」與「修改內容」（選填），按「存檔」。
4. 要回復舊版本時，切換到「復原」，選擇版本後按「恢復」。

程式固定管理 **EXE 所在資料夾**，不需要另外選擇路徑。

備份會儲存在同一目錄的 `.versions` 子資料夾：

```text
myproject/
├── folder-versions.exe
├── index.php
├── src/
└── .versions/
    ├── 20261109-112000-123.zip
    └── 20261109-140000-456.zip
```

建立快照時會自動排除 `.versions` 及目前執行中的 EXE，避免把備份檔再次壓縮進去。

## 還原規則

目前採用 **覆蓋還原**：

- 快照內有的檔案，會覆蓋目前的同名檔案。
- 目前存在、但快照內沒有的檔案，**不會刪除**。
- 還原前會自動建立安全快照，保存在 `.versions` 中。

> 建議先在測試資料夾確認操作。還原時請先關閉正在修改該資料夾檔案的其他程式；備份與還原不等於可防範硬碟損壞的異地備援。

## 編譯

需要 Windows、Rust 工具鏈，以及對應的 MSVC C++ Build Tools。

執行 `build_windows.bat`，或在專案目錄輸入：

```powershell
cargo build --release
```

輸出位置：

```text
target/release/folder-versions.exe
```

也可透過專案內的 GitHub Actions 工作流程編譯 Windows EXE。
